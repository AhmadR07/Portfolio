Deep Learning • Computer Vision • Medical Imaging

ScanEvidence — Brain Tumor Detection & Explainable AI

ScanEvidence is a deep-learning-based medical imaging project focused on analyzing brain MRI scans for brain tumor detection and providing interpretable model predictions. The project explores the use of computer vision and explainable AI to make deep-learning-based medical image analysis more transparent and easier to understand.

The system works with MRI brain scans and applies image preprocessing before passing the data through deep-learning models for feature extraction and classification. I experimented with multiple CNN and transformer-based architectures, including ResNet50, EfficientNet, and Vision Transformer (ViT), to study their effectiveness for medical image analysis. The project also incorporates Explainable AI techniques such as SHAP and LIME to analyze model predictions and identify the image regions or features that contribute to the model's decision.

Note: Built as an exploratory student research project studying model interpretability on public MRI benchmarks. Not a clinically deployed diagnostic system.

Natural Language Processing • Distributed Systems • Transformers

ChatGPT-Neo — Large-Scale Autoregressive Language Model

ChatGPT-Neo is a maintained and extended implementation of a GPT-3-like autoregressive language-modeling system built around Mesh-TensorFlow. The project supports model and data parallelism and is designed to train and run large transformer-based language models across TPUs and GPUs.

I worked on maintaining and adapting the GPT-Neo codebase, including its training configuration, dataset pipeline, tokenizer workflow, model configuration, and inference setup. The project supports different model sizes, configurable transformer architectures, distributed training, and multiple attention mechanisms.

Full-Stack Web • Real-Time WebSockets • FastAPI

Event Planner — University Event Management & Real-Time Ticketing

A full-stack university event management platform engineered to streamline campus event discovery, multi-stage attendee registration, dynamic QR-code virtual ticketing, and real-time announcement broadcasts.

Key Features:

  • Event Discovery: Users can browse university events by category and view live countdown timers.
  • Event Registration: Students can register using their name and university email and receive a unique Ticket ID.
  • Registration Tracking: A four-stage status workflow tracks participants through Registered → Under Review → Shortlisted → Confirmed.
  • Virtual Tickets: Confirmed participants receive a digital ticket containing their Ticket ID and dynamic QR code (QRCode.js).
  • Real-Time Announcements: Native WebSockets deliver announcements to connected users instantly without page refreshes.
  • Admin Dashboard: Administrators can view event statistics, manage participants, confirm/reject attendees in bulk, and export CSVs.

Technical Implementation: The application uses FastAPI as the backend framework and SQLAlchemy as the ORM layer for interacting with the SQLite database, with Uvicorn running as an ASGI server. Jinja2 templates provide the server-rendered interface styled with Tailwind CSS and Alpine.js. WebSocket connections through FastAPI broadcast announcements in real time, while QRCode.js integrates dynamic pass generation for on-site event entry.
